## `whoami` 👨‍💻

I'm **Nikhil**, a developer and product builder who enjoys turning ideas
into useful, well-crafted software. I work across **web development,
mobile apps, and AI/ML**, while contributing to open source and building
products for real-world problems.

-   🧩 **Full-stack:** MERN, TypeScript, REST APIs, SQL and PostgreSQL
-   📱 **Mobile:** React Native and Flutter
-   🤖 **AI/ML:** Exploring and building AI-powered applications and
    machine-learning projects
-   🚀 **Builder:** Developing products, prototypes, and experiments
    from idea to deployment
-   🌱 **Open source:** Learning in public, collaborating, and making
    meaningful contributions
-   💼 **Freelancer:** Helping turn product ideas into working software
-   🏢 **Experience:** Interned at **Eglogics**, a Noida-based company

> **My approach:** Ship useful things, keep learning, and leave the
> codebase better than I found it.
